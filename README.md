# תפוס 💻 - מערכת לניהול השאלת מחשבים בבית הספר

מערכת חכמה, מודרנית ואינטואיטיבית לניהול השאלת עגלת מחשבים ניידים בית ספרית (12 מחשבים ממוספרים), מותאמת במיוחד לטלפונים ניידים, טאבלטים ומחשבים שולחניים.
בפונט אלמוני (Almoni) אחיד ובניסוח זכר ישיר ונוח.

---

## 📱 מסכי האפליקציה

### 1. מסך כניסה והרשמה (Login Screen)
- **לוגו האפליקציה הרשמי** מופיע בגאווה בראש המסך.
- **שדה חובה להזנת שם המורה:** כל משתמש מזין תחילה את שמו המלא.
- **התחברות באמצעות חשבון Google:** חלון נקי וממוקד להזנת כתובת אימייל גוגל בלבד (ללא בקשת שם כפולה וללא בחירה מהירה), עם כפתור "כניסה למערכת" וכפתור "ביטול".
- **הקלדת כתובת מייל (ללא גוגל):** אפשרות להזין ישירות כל כתובת דוא"ל בית ספרית וללחוץ על "כניסה למערכת".
- **זכור אותי (Remember Me):** שמירת החיבור כך שהכניסות הבאות יובילו ישירות למסך הבית ללא צורך בהתחברות חוזרת.
- **עיצוב נקי וברור:** הוסרו כפתורי הבחירה המהירה וקישורי הברקוד מתחת לכפתור הכניסה לטובת ממשק ממוקד ונקי.

### 2. מסך הבית (Home Screen - כשהמחשב לא ברשות המורה)
- **Header עליון נקי**: לוגו האפליקציה, ברכת שלום אישית ("שלום, רחל"), תמונת פרופיל / אווטאר, ותפריט ניווט/התנתקות.
- **כרטיסת זמינות (Counter Card)**: קובייה מרכזית בעיצוב בהיר ונקי (ירוק מנטה עדין), עם מד התקדמות ומספרים גדולים: **8 מחשבים פנויים (מתוך 12)**.
- **כפתור פעולה ראשי ענק (CTA)**: כפתור כחול עמוק, מרשים ואינטואיטיבי עם אייקון מחשב: **"💻 קח מחשב פנוי"**.
- **זרימת לחיצה**:
  1. המסך מבצע רענון קצר (אנימציית איתור מחשב פנוי).
  2. נפתח דיאלוג אישור ובו כיתוב מוגדל ומובלט:  
     **"נבחר עבורך מחשב מספר 1 מעגלת המחשבים"**  
     ומתחתיו 2 אפשרויות ברורות ללא מספרים:
     - **לקחתי**
     - **התחרטתי, החזר מחשב**
  3. בלחיצה על "לקחתי" – המחשב מוקצה למורה מיד!

### 2ב. כאשר המחשב ברשות המורה (Active Loan State)
- **הווידג'ט הצף (Floating Banner)**:
  - מוצמד לראש המסך ונשאר קבוע גם בגלילה (`Sticky / Fixed`).
  - רקע כחול-טורקיז עמוק עם טקסט לבן חד ונקודת פולס חיה.
  - תוכן: **"💻 מחשב מס' 3 אצלך כרגע"** לצד **טיימר רץ בזמן אמת** (למשל: `אצלך כבר 00:35:12`).
  - כפתור אדום בולט בתוך הווידג'ט: **"לחץ להחזרה"**.
- **בשאר המסך מתחת לווידג'ט**:
  - כרטיסת אישור ירוקה: **"המחשב הוקצה לך בהצלחה. תהנה בשיעור! 🎉"**
  - הסבר קצרצר: *"הווידג'ט למעלה יישאר זמין עבורך לאורך כל היום. כשתחזיר את המחשב פיזית לעגלה, פשוט לחץ על 'החזרה'."*
- **כפתור "קח מחשב פנוי"**:
  - הופך ללא זמין ללחיצה (Disabled), ומופיע עליו כיתוב ברור: **"מחשב מספר 3 ברשותך. לא תוכל להשאיל מחשב נוסף."**
- **לחיצה על "לחץ להחזרה"**:
  - הווידג'ט נעלם מיד.
  - מופיעה הודעת הצלחה ירוקה: **"המחשב הוחזר בהצלחה, תודה!"**
  - צליל החזרה נעים מופעל.
  - המסך חוזר למצב ההתחלתי שבו הכפתור "קח מחשב פנוי" זמין שוב.

### 2ג. לבחירת מחשב מסוים מהעגלה (לוח 12 המחשבים)
- בחלק התחתון של מסך הבית מוצג לוח כפתורים מעוצב של כל 12 המחשבים (1 עד 12):
  - כותרת: **"לבחירת מחשב מסוים מהעגלה"**
  - תת-כותרת (בקטן יותר): **"לבחירה לחץ על מחשב פנוי"**
  - תצוגת מספרים נקייה: **1, 2, 3 ... 12** (ללא קידומת #01).
  - מציג בצבעוניות ברורה:
    - 🟢 **פנוי להשאלה** (ירוק – ניתן ללחוץ עליו כדי להשאיל מחשב ספציפי אם אין מחשב ברשות המורה).
    - 🔴 **תפוס** (אדום – מציג אצל מי המחשב נמצא כעת).
    - 🔵 **המחשב שלך** (כחול בולט עם כוכב וזוהר).

### 3. מסך ניהול / רכז התקשוב (Admin Screen)
מסך נפרד הנגיש לרכז התקשוב (מזוהה ע"י הרשאת מייל או דרך תפריט הניהול):
- **כותרת**: "ניהול עגלת מחשבים".
- **כרטיסיות סטטיסטיקה מהירה**: מספר פנויים, מספר תפוסים וסה"כ בעגלה.
- **כפתור עקיפה כללי (Release All)**:
  - **"🔄 שחרר את כל המחשבים התפוסים בעגלה"** – מאפשר לרכז לאפס בבת אחת את כל המחשבים (למשל בסוף יום הלימודים) עם דיאלוג אישור.
- **תצוגת רשימה (List View)**:
  - טבלה נקייה וברורה המציגה את כל 12 המחשבים (מחשב 1 עד מחשב 12).
  - לכל מחשב מוצגים:
    1. **מספר המחשב** (מחשב 1 - 12)
    2. **תגית סטטוס** (ירוק "פנוי" / אדום "תפוס")
    3. **שם המורה והמייל** (למשל: "אצל: שרה כהן")
    4. **זמן השאלה בזמן אמת** (למשל: "⏱️ שעתיים ו-15 דק' (02:15:30)")
    5. **כפתור עקיפה ידני (Manual Reset)**: כפתור קטן "🔓 שחרר מחשב" לשחרור נקודתי אם מורה שכח להחזיר.

## 🚀 הפעלת האפליקציה

השרת רץ באופן מובנה באמצעות Python (ללא צורך בהתקנת חבילות נוספות):

```bash
# הרצת השרת
py server.py
```

### כתובות גישה:
- **מהמחשב הנוכחי**: [http://localhost:8000](http://localhost:8000)
- **מהטלפון הנייד של המורים (ברשת ה-WiFi של ביה"ס)**: `http://10.100.102.8:8000` (או סריקת קוד ה-QR מהאפליקציה).
- **עבודה אופליין**: ניתן גם לפתוח ישירות את קובץ `index.html` בכל דפדפן (כולל תמיכה מלאה ב-localStorage).
